# Code rules

## Content / copywriting

- **No em dashes (`—`) in user-facing text.** Use a comma instead. This applies to
  all copy rendered to users (component templates, service/section data strings,
  marketing copy). Code comments are exempt.
  - ✅ `scale with your business, not slow it down.`
  - ❌ `scale with your business — not slow it down.`
- **No semicolons (`;`) in user-facing text.** They read as AI-written. Split into
  separate sentences or use commas instead. Code and code comments are exempt.
  - ✅ `Angular and TypeScript on the frontend. Node.js on the backend.`
  - ❌ `Angular and TypeScript on the frontend; Node.js on the backend.`
